# Agent Race — 24-second Motion Graphics

## Purpose

Explain the hackathon prototype before or alongside the live demo. This is explicitly labeled as a concept visualization, not prototype footage.

## Sequence

1. **0–3.2s — Hook:** “Agents, start your engines.”
2. **3.2–6.4s — Technology:** Each agent sees, decides, and drives using Agents API and computer use.
3. **6.4–9.5s — Setup:** Shared circuit, two agent panels, countdown.
4. **9.5–21.2s — Race:** Two cars circle the track while independent decision callouts appear.
5. **21.2–24s — Close:** “Autonomy you can watch.”

## Output

- Format: 1920×1080, 30 fps, H.264/AAC
- Duration: 24 seconds
- File: `agent-race-cinematic-v3.mp4`
- Visual direction: black outdoor event stage, luminous red track edge, white cars with agent-color accents, and cinematic wide framing. Inspired by the atmosphere of the 2026 Roadster event without using Tesla branding or source assets.

The final cinematic uses original AI-generated key art derived from the
reference mood—not Tesla imagery or vehicle designs—with a slow camera move
and animated agent telemetry.
